# Run Details

Run Details lists every run of the active identity, newest first. Open any run to see what it did, what it found, the ideas it produced and what it cost. The page is titled **Run History**.

To start a run, click **Generate Now**; see [Starting a Run](/docs/account-setup/runs).

## Spending at a glance

Once you have runs, four cards sit above the list:

| Card                  | What it shows                                                                            |
| --------------------- | ---------------------------------------------------------------------------------------- |
| **Last 7 days**       | What runs from the last 7 days cost, how many there were and how many tokens they wrote. |
| **Last 30 days**      | The same for the last 30 days.                                                           |
| **Average per run**   | The average cost of runs that have a recorded cost.                                      |
| **Projected monthly** | A month's cost at the last 7 days' pace.                                                 |

These count runs only. AI spending outside runs, such as newsletters or identity setup, is on the [Dashboard](/docs/getting-started/dashboard).

## The run list

Each row shows the identity's name as it was when the run started, the status, how the run was started (**Manual** or **Schedule**), its date and time, a short ID and the goals it was for. A failed run shows its error in red. On the right are the cost, the tokens, a stage counter such as "Stage 2/3" and **View Run**, which opens the run.

The list updates itself every few seconds while a run is moving, and notices runs started elsewhere, such as by your schedule.

## Run statuses

| Status                     | What it means                                                                        |
| -------------------------- | ------------------------------------------------------------------------------------ |
| **Queued**                 | Waiting to start. A run can wait here briefly if the server is busy with other runs. |
| **Running**                | Started, and gathering your identity's context.                                      |
| **Researching**            | Searching the web, news and trends, and reading your knowledge base and newsletters. |
| **Ideating**               | Writing ideas and checking them.                                                     |
| **Awaiting Idea Approval** | Ideas are ready. Some wait for your review, or approved ideas wait to become posts.  |
| **Drafting**               | Posts are being written from approved ideas.                                         |
| **Completed**              | No idea is left to review and every approved idea has become a post.                 |
| **Failed**                 | The run ended with an error and saved no ideas. The message says why.                |
| **Stopped**                | You stopped it. It saved no ideas.                                                   |

A completed run goes back to Awaiting Idea Approval if you later approve one of its ideas, for example one you had rejected.

## Inside a run

A run's page shows "Run for" and the identity's name, the status next to it, **Back to Runs** above it and the run's goals underneath.

### Progress

Four cards follow the stages: **Gathering context**, **Researching web & KB**, **Generating ideas** and **Drafting posts**. Each says where the stage stands, such as how long it took, "In progress…", "Failed", "Stopped" or "Not started". Drafting shows "Waiting for idea approval" until you create posts, then how many were written. Failed steps are listed underneath with their error.

While the run is working, **Stop analysis** stops it. Once it has finished, **Re-analyze** starts a new run for the same goals and platform choice. The old run, its ideas and their posts stay, and because those ideas now count as earlier work, the new run looks for fresh angles.

### Tokens and cost

The **Tokens & cost** panel shows the **Total cost**, the **Cost per post** (the run's cost shared across the posts written from it), **Output tokens** and the **Cache hit rate**, then a table breaking the cost down by stage: **Ideation**, **Drafting**, **Revision pass** and **Media (brief + image)**. If some calls came back without a price, a note says the total may be slightly low.

### Ideas from this run

**Ideas** lists the run's ideas with a summary such as "3 to review · 2 approved". The cards work as on the Ideas page: approve, reject, edit and read each scorecard. At the top, **Approve all** and **Select 2 approved** (with your count) work as there, and ticking ideas shows **Create 2 posts**. Posts created here open on the Posts page filtered to this run. **Open in Ideas** goes to the Ideas page.

If a goal you picked ended up with no idea, a warning names it, says why and suggests another run or more knowledge base sources about it.

### Research sources and settings

**Research sources** lists what the run found, with each source's site (or "Knowledge base"), how far that kind of source can be trusted, what it was found for and its date. **Run configuration**, folded at the bottom, shows the run ID, how it was started and the settings it ran with.

## When a run fails

A failed run shows **This run failed** in a red box, with the reason. It saves no ideas, but what it spent before failing still counts.

| Message starts with                                     | What happened                                                                                                                                                    |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| "No idea survived grounding and novelty checks."        | Every idea was dropped: its facts had no sources, it missed its goal, or it repeated earlier work. Adding knowledge base sources about your goals usually helps. |
| "The run took longer than"                              | It hit its time limit and was stopped.                                                                                                                           |
| "The server stopped while this run was in progress."    | The server restarted mid-run.                                                                                                                                    |
| "None of the goals picked for this run exist any more." | Its goals were deleted after it was queued.                                                                                                                      |
| "None of the goals picked for this run are for"         | It was planned for one platform, but none of its goals are meant for it.                                                                                         |

A run also fails at once if an AI spending limit has been reached; the message says which. Fix the cause, then start a new run. **Re-analyze** is quickest when the run's goals still exist.
